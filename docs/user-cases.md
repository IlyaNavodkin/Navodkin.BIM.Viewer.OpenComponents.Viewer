# User Cases

## Контекст

Продукт: BIM/IFC Viewer с проектами, 3D-пространством, деревом элементов и панелью свойств.

Основные сущности:

- Проект
- IFC-модель
- Элемент модели
- Свойства элемента
- Выделение
- Вложенные элементы

## Юзер-кейсы

### 1. Создание проекта

**Название:** Создание нового проекта

**Роль:** Пользователь

**Цель:** Создать проект, чтобы открыть рабочее 3D-пространство и начать загрузку IFC-моделей.

**Триггер:** Пользователь нажимает кнопку `Создать проект`.

**Основной сценарий:**

1. Пользователь открывает форму создания проекта.
2. Вводит `Имя проекта`.
3. Вводит `Описание проекта`.
4. Нажимает `Создать`.
5. Система создает проект.
6. Пользователь попадает в экран проекта с 3D-пространством.

**Данные формы:**

- Имя проекта
- Описание проекта

**Состояния:**

- Пустая форма
- Валидация обязательных полей
- Загрузка при создании
- Успешное создание
- Ошибка создания

**Критерии приемки:**

- Поле `Имя проекта` обязательно.
- Поле `Описание проекта` необязательно.
- После успешного создания открывается экран 3D-пространства проекта.
- Если создание не удалось, пользователь видит понятное сообщение об ошибке.

### 2. Открытие рабочего пространства проекта

**Название:** Открытие 3D-пространства проекта

**Роль:** Пользователь

**Цель:** После создания проекта попасть в основное рабочее пространство.

**Основной сценарий:**

1. После создания проекта система открывает экран проекта.
2. На экране отображаются:
   - центральная 3D-сцена
   - левый сайдбар `Дерево элементов`
   - правый сайдбар `Свойства`
   - управляющий элемент `Диспетчер моделей`

**Критерии приемки:**

- Рабочая область открывается автоматически после создания проекта.
- 3D-сцена доступна даже если модели еще не загружены.
- Если в проекте нет моделей, отображается пустое состояние.

### 3. Управление IFC-моделями через диспетчер моделей

**Название:** Управление моделями проекта

**Роль:** Пользователь

**Цель:** Просматривать загруженные модели, удалять их и добавлять новые IFC-модели в проект.

**Триггер:** Пользователь нажимает на `Диспетчер моделей`.

**Основной сценарий:**

1. Пользователь нажимает `Диспетчер моделей`.
2. Открывается модальное окно.
3. В модальном окне отображается список уже загруженных моделей.
4. Пользователь может:
   - загрузить новую IFC-модель
   - удалить существующую модель
5. После загрузки новая модель появляется в 3D-пространстве и в дереве элементов.
6. После удаления модель исчезает из 3D-пространства и дерева элементов.

**Данные в модальном окне:**

- Список моделей
- Имя модели
- Статус загрузки
- Действия `Загрузить`, `Удалить`

**Состояния:**

- Список пуст
- Идет загрузка модели
- Модель успешно загружена
- Ошибка загрузки
- Подтверждение удаления
- Ошибка удаления

**Критерии приемки:**

- Модальное окно показывает все модели текущего проекта.
- Пользователь может загрузить одну или несколько IFC-моделей.
- Удаление модели требует явного подтверждения.
- После загрузки или удаления интерфейс обновляется без перезагрузки страницы.

### 4. Просмотр дерева элементов проекта

**Название:** Навигация по дереву элементов

**Роль:** Пользователь

**Цель:** Просматривать структуру элементов загруженных моделей и быстро находить нужный элемент.

**Расположение:** Левый сайдбар `Дерево элементов`

**Состав экрана:**

- Поле поиска по названию элемента
- Дерево элементов по проекту и моделям
- Вложенные узлы с возможностью раскрытия

**Поведение выделения в левом сайдбаре:**

- `Click` выделяет один элемент и снимает предыдущее выделение.
- `Ctrl + Click` добавляет или снимает один элемент из текущего выделения.
- `Shift + Click` выделяет диапазон от anchor-элемента до текущего элемента.
- Диапазон считается по текущему видимому порядку дерева.
- Для диапазона не имеет значения уровень вложенности элемента.
- Если ветка свернута, скрытые элементы в диапазон не попадают.
- Если ветка раскрыта, видимые элементы в диапазон попадают.
- `Ctrl + Shift + Click` добавляет диапазон от anchor-элемента до текущего в уже существующее выделение.
- Визуально все выделенные элементы выглядят одинаково.

**Основной сценарий:**

1. Пользователь открывает проект с загруженными моделями.
2. В левом сайдбаре видит дерево элементов.
3. Раскрывает нужные уровни вложенности.
4. Использует поиск по названию элемента.
5. Находит нужный элемент.
6. Дважды нажимает на элемент.
7. Система выделяет соответствующий элемент в 3D-модели.

**Особенности UI:**

- Минимальные отступы
- Небольшой размер шрифта
- Компактное отображение для глубокой вложенности
- Текст в дереве не выделяется мышью
- Поддержка множественного выделения в стиле desktop-приложений

**Состояния:**

- Дерево пустое
- Дерево загружается
- Дерево отфильтровано поиском
- Ничего не найдено

**Критерии приемки:**

- Дерево поддерживает большую вложенность.
- Поиск работает по названию элемента.
- Двойной клик по элементу выделяет его в 3D-сцене.
- Левый сайдбар поддерживает выделение через `Click / Ctrl + Click / Shift + Click / Ctrl + Shift + Click`.
- Текст в левом дереве не выделяется при drag и кликах мышью.
- Дерево остается компактным и пригодным для плотной структуры.

### 5. Контекстное меню в дереве элементов

**Название:** Контекстные действия над элементами дерева

**Роль:** Пользователь

**Цель:** Быстро копировать данные элемента из дерева через контекстное меню.

**Триггер:** Пользователь нажимает правой кнопкой мыши на элемент дерева.

**Основной сценарий:**

1. Пользователь нажимает правой кнопкой мыши на элемент дерева.
2. Открывается контекстное меню.
3. Пользователь выбирает `Копировать айди` или `Копировать имя`.
4. Система копирует выбранное значение в буфер обмена.

**Правила:**

- Контекстное меню одинаковое для всех элементов дерева.
- В меню доступны только действия `Копировать айди` и `Копировать имя`.
- `Копировать айди` копирует внутренний id узла дерева.
- `Копировать имя` копирует отображаемое имя элемента.

**Критерии приемки:**

- Контекстное меню открывается по правому клику.
- В контекстном меню нет других действий кроме `Копировать айди` и `Копировать имя`.
- После выбора действия значение попадает в буфер обмена.

### 6. Просмотр свойств выбранного элемента

**Название:** Просмотр свойств элемента

**Роль:** Пользователь

**Цель:** После выбора элемента видеть property sets и свойства со значениями.

**Расположение:** Правый сайдбар `Свойства`

**Состав экрана:**

- Поле поиска по имени, типу и значению свойства
- Табличное отображение свойств
- Группировка по property sets
- Колонки таблицы: `Имя / Тип / Значение`

**Основной сценарий:**

1. Пользователь выбирает элемент в сцене или в дереве.
2. Правый сайдбар обновляется.
3. Пользователь видит property sets выбранного элемента.
4. Пользователь видит список свойств и их значений.
5. Пользователь использует поиск по имени, типу или значению.
6. Таблица фильтруется по введенному запросу.

**Особенности UI:**

- Минимальные отступы
- Маленький размер шрифта
- Табличный компактный вид

**Состояния:**

- Элемент не выбран
- Свойства загружаются
- Свойства отображены
- Ничего не найдено по поиску
- Ошибка получения свойств

**Критерии приемки:**

- Свойства отображаются только для выбранного элемента.
- Поиск работает по имени свойства, типу и значению.
- Данные сгруппированы по property sets.
- Для каждой строки свойства отображаются `Имя`, `Тип` и `Значение`.
- Таблица остается читаемой при большом количестве свойств.

## Сквозной сценарий

### 7. Полный пользовательский сценарий

**Название:** Создание проекта и работа с IFC-моделью

**Основной сценарий:**

1. Пользователь создает проект, заполняя имя и описание.
2. Система открывает рабочее 3D-пространство проекта.
3. Пользователь открывает `Диспетчер моделей`.
4. Загружает одну или несколько IFC-моделей.
5. Модели появляются в сцене и в дереве элементов.
6. Пользователь ищет элемент в левом сайдбаре через поиск.
7. Дважды нажимает на элемент и видит выделение в 3D.
8. Нажимает правой кнопкой на элемент в дереве и использует `Копировать айди` или `Копировать имя`.
9. Выбранный элемент отображается в правом сайдбаре `Свойства`.
10. Пользователь ищет нужное свойство по имени, типу или значению.
11. Пользователь работает с множественным выделением в левом дереве через `Click / Ctrl + Click / Shift + Click / Ctrl + Shift + Click`.

## Состав экранов

1. Экран `Создание проекта`
2. Экран `Рабочее пространство проекта`
3. Модальное окно `Диспетчер моделей`
4. Левый сайдбар `Дерево элементов`
5. Правый сайдбар `Свойства`

## Открытые вопросы

- Что происходит при двойном клике: только выделение или еще и фокус камеры?
- Можно ли загружать несколько IFC сразу?
- Нужно ли хранить выбранную модель или элемент после повторного открытия проекта?
- Нужна ли индикация скрытых, удаленных или ошибочных моделей?
- Нужна ли сортировка в дереве и в свойствах?
